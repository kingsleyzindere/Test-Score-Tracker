# Test Score Tracker

A C# console application that collects three valid test scores and calculates their total and average.

## Features

- Accepts whole-number scores from 0 to 100.
- Handles text input and numbers outside the allowed range.
- Keeps asking until three valid scores are entered.
- Displays all scores, their total, and their average.
- Formats the average to two decimal places.

## How to Run

1. Clone or download this repository.
2. Open the solution in Visual Studio 2022 with the .NET desktop development workload installed.
3. Press Ctrl + F5 to run.
4. Enter three test scores when prompted.
